<h1>모던 리액트 Deep Dive 스터디</h1>

- 도서명 : 모던 리액트 Deep Dive
- 일정 : 매주 수요일 오후 8시
- 진행 방식
  - 매주 정해진 분량을 읽고 MarkDown File로 정리해서 PR을 스터디 전날까지 올린다.
  - 스터디간 공유하면 좋을 내용이나 정보들도 함께 첨부할 수 있도록 노력한다.

<h2>파일 작성 방법</h2>

- 각 주차별로 `name/week-nn` branch를 만들어서 MarkDown File에 내용을 정리하여 PR을 생성한다.

- MarkDown File 이름은 `name.md`로 한다.

- 예시구조

```text
week-01
ㄴ README.md // 각 주차 설명 README.md
ㄴ name1.md
ㄴ name2.md
week-02
ㄴ README.md
ㄴ name1
  ㄴ index.md
  ㄴ some-image.png // 필요시 첨부되는 Image File
  ㄴ ...
ㄴ name2.md
```
